# 😀 Uno Q Internet Radio

An application that let's you use the Uno Q as an Internet Radio Player


* Modulino Buttons: A = previous / hold volume down, B = play-pause / hold mute, C = next / hold volume up
* 13x8 LED matrix: station number, play state icon, volume bar on the bottom row
* Audio: USB sound card on a powered USB-C hub, into a powered speaker
* Stations: edit `python/stations.json` (direct URL and/or Radio Browser search)

Requires the `Arduino_Modulino` library (add it from the sketch Libraries panel in App Lab).
First run downloads the Python packages in `python/requirements.txt`, so it takes a few minutes.
